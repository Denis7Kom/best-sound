# BEST SOUND — Concert Agency

Сайт концертного агентства BEST SOUND с кинематографичной структурой каталога: большой экран с артистом, горизонтальные подборки, интерактивный архив гастролей, поиск, карточки артистов и контакты.

## Что нужно прислать для завершения

Полный чек-лист исходных материалов, контента, юридических данных и настроек: **[CONTENT_REQUEST.md](./CONTENT_REQUEST.md)**.

## Запуск и публикация

Это обычный статический сайт без сборщика, npm и серверной части.

- Русский (основной): `index.html`
- English: `lang-en.html`
- Italiano: `lang-it.html`

Все языки используют один шаблон `src/showcase.js` и одни стили `src/showcase.css`. Это предотвращает расхождение верстки при изменениях.

Локальный просмотр:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000/`.

GitHub Pages: **Settings → Pages → Deploy from a branch → main → /root**. Ожидаемый URL: `https://denis7kom.github.io/best-sound/`.

## Источники и актуальность

Тексты об агентстве, артисты, концерты и даты подготовлены по публичным материалам [BEST SOUND](https://sound-agency.ru/). Даты 2022–2026 представлены **только как архив**; это не актуальная билетная афиша. Информации о новых продажах билетов сайт не заявляет.

**Изображения артистов сейчас загружаются с внешних ресурсов**. Использованы фото исполнителей для визуальной сборки:
- `safina.top/photos/safina-3.jpg`;
- `bstars.eu/media/djcatalog2/images/item/9/alessandro-safina.1.jpg`;
- `rockthenight.eu/wp/wp-content/uploads/2023/11/ahat-joe-lynn-turner-7798.jpg`;
- `vice.com/wp-content/uploads/sites/2/2017/07/1499675776591-FedericoPaciotti1003_phPaoloDeFrancesco-scaled.jpeg`.

Изображения **не принадлежат автоматически владельцу этого репозитория**. Перед коммерческим использованием нужно получить права на фотографии или заменить их оригинальными одобренными материалами BEST SOUND, поместить файлы в `assets/` и изменить пути в `src/showcase.js`. Внешняя загрузка изображений также зависит от доступности серверов-источников.
